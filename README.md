# 项目名称
图书管理系统

## 项目简介
本项目是一个简易的图书管理系统，使用Java + Spring + MyBatis开发，实现图书信息管理、用户借阅、归还等基础功能，用于课程实践练习，熟悉Git版本控制与GitHub代码托管流程。

## 功能介绍
1. 用户登录注册
2. 图书信息新增、查询、修改、删除
3. 图书借阅操作
4. 图书归还操作
5. 借阅记录查看

## 开发环境
- 操作系统：Windows
- JDK版本：1.8
- 开发工具：IDEA
- 数据库：MySQL
- 框架：Spring、MyBatis
- 版本控制：Git + GitHub（SSH方式提交代码）
